# CanaGuard

> Sistema de monitoramento de perdas na colheita de cana-de-açúcar.

## Problema no agronegócio

A colheita mecanizada de cana-de-açúcar pode apresentar perdas de produção. Quando os dados de área, produtividade esperada e produção efetivamente colhida não são registrados e analisados por talhão, o produtor tem mais dificuldade para identificar perdas críticas e estimar seus impactos financeiros.

## Solução proposta

O CanaGuard será um programa em Python executado via terminal para cadastrar registros de colheita, calcular perdas e prejuízos estimados, classificar o nível de risco e persistir dados em JSON, TXT e Oracle.

## Escopo técnico

- Python com funções, procedimentos e parâmetros
- Lista, tupla e dicionário
- Validação de entradas
- Manipulação de arquivos TXT e JSON
- Conexão com Oracle
- Menu interativo no terminal
